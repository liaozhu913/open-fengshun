# 开源丰顺 (OpenFengshun)

> 用开源 + AI 打造丰顺县最全本地生活目录，可持续变现。

## 一句话定位

**丰顺人的生活指南** —— 整合丰顺县 16 个镇的商家、服务、资源信息，开源共建，AI 驱动，靠精准流量变现。

## 为什么是丰顺？

| 维度 | 数据 |
|------|------|
| 常住人口 | 47.8 万（户籍 73 万） |
| 核心产业 | 电声制造（全国两大扬声器基地之一）、温泉旅游 |
| 旅游资源 | 国家 AAAA 景区 2 个、AAA 景区 5 个，"中国温泉之城" |
| 文化特色 | 潮客文化交融，埔寨火龙 |
| 数字化程度 | 低 —— 无本地生活聚合平台，信息碎片化严重 |
| 竞争格局 | 无垂直目录网站，信息散落在公众号、抖音、美团 |

**核心判断：** 丰顺有真实需求（旅游+本地生活），但信息极度碎片化，用 AI + 开源做目录成本极低，ROI 高。

## 商业模式

### 变现路径（按优先级）

1. **商家收录 + 增值服务**（核心收入）
   - 免费收录基础信息（名称、地址、电话）
   - 付费增值：优先展示、图片轮播、详细页面、优惠券发布
   - 定价：99-499 元/年/商家

2. **旅游导流佣金**
   - 温泉酒店、景区门票预订导流
   - 携程/美团 CPS 分成

3. **本地广告**
   - Banner 位、推荐位
   - 本地房地产、培训机构等广告主

4. **数据服务**
   - 向研究机构/政府部门提供丰顺商业数据报告

### 收入预估（Year 1 保守）

- 500 家收录商家 × 20% 付费 × 199 元/年 ≈ 2 万元
- 旅游导流佣金 ≈ 1-3 万元
- 本地广告 ≈ 1-2 万元
- **首年目标：5-7 万元**（轻量副业级别）

### 长期想象空间

- 模式可复制到其他县级市（梅州市其他县、揭阳等）
- 开源社区贡献数据，形成网络效应
- 成为"县域生活基础设施"

## 技术方案

### 开源技术栈

| 层次 | 技术 | 说明 |
|------|------|------|
| 前端 | Next.js + Tailwind | SSR/SEO 友好，开源 |
| 后端 | Node.js / Python FastAPI | 轻量 API |
| 数据库 | Supabase (PostgreSQL) | 开源 BaaS，免费额度够用 |
| 搜索 | Meilisearch | 开源全文搜索，中文友好 |
| CMS | 自建 + Markdown | 内容可版本控制 |
| 部署 | Vercel / Cloudflare Pages | 免费托管 |
| 数据采集 | Crawl4AI + Claude | AI 驱动爬虫和清洗 |

### AI 应用点

1. **数据采集**：从 Google Maps / 百度地图 / 大众点评批量抓取丰顺商家
2. **数据清洗**：AI 自动去重、补全、分类
3. **内容生成**：自动为商家生成简介、标签
4. **图片识别**：Claude Vision 筛选高质量商家图片
5. **SEO 优化**：AI 生成长尾关键词页面
6. **对话式搜索**：用户可以自然语言查找（"帮我找个能泡温泉的地方"）
