# 开源丰顺 - 飞书多维表格共建说明

## 表格用途

这是一个**开放共建的丰顺县本地生活目录**，任何人都可以提交商家信息、修正错误、更新数据。数据会自动同步到开源丰顺网站。

## 表格字段设计

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 商家名称 | 文本 | 店名/单位名（必填） | 鹿湖温泉度假村 |
| 分类 | 单选 | 所属类别（必选） | 餐饮、住宿、温泉、旅游、医疗、政务办事、银行、快递物流、教育、生活服务、购物、交通出行 |
| 子分类 | 单选 | 细分类别 | 火锅、农家乐、酒店、银行网点、卫生院... |
| 所属镇 | 单选 | 丰顺16个镇（必选） | 汤坑镇、留隍镇、丰良镇... |
| 详细地址 | 文本 | 尽量写到门牌号 | 汤坑镇金河大道1号 |
| 联系电话 | 电话 | 店铺/单位电话 | 0753-6888888 |
| 营业时间 | 文本 | 统一格式 | 08:00-22:00 或 24小时 |
| 简介/特色 | 文本 | 一句话介绍，突出特色 | 国家AAAA景区，22个特色温泉池 |
| 价格区间 | 文本 | 参考消费 | 人均60-80元 |
| 评分 | 数字 | 1-5分，凭口碑打分 | 4.5 |
| 标签 | 多选 | 快速标签 | 免费、老字号、亲子、24小时、网红... |
| 照片 | 附件 | 商家/景点照片 | 上传1-3张 |
| 提交人 | 文本 | 你的名字（可匿名） | 小明 |
| 状态 | 单选 | 审核状态 | 待审核、已收录、需补充 |

## 怎么提交？

### 方式一：直接编辑表格（推荐）
1. 打开表格链接
2. 底部空白行直接填写
3. 每行一个商家/地点
4. 填完自动保存

### 方式二：发消息给我
直接发给我，格式：
```
【店名】xxx
【地址】xxx
【电话】xxx
【特色】xxx
```
我来帮你录入。

## 数据怎么用？

- **网页浏览**：开源丰顺网站自动同步
- **导出数据**：支持导出 Excel/CSV
- **API调用**：开源数据可自由使用
- **分享给朋友**：直接转发表格链接

## 共建规则

1. ✅ 真实信息，不编造
2. ✅ 不删除别人提交的内容
3. ✅ 发现错误可以修正
4. ✅ 欢迎补充照片和详细信息
5. ❌ 不发广告、垃圾信息
